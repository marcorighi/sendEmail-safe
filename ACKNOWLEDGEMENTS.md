# Acknowledgements

This project originated from a practical security problem identified by Marco Righi: legacy shell scripts passed a Brevo SMTP credential to `sendEmail` through `-xp`, making the credential observable in the process command line.

The software and documentation were developed through an interactive collaboration with ChatGPT by OpenAI. Marco Righi supplied the requirements, constraints, deployment context, compatibility target, and validation feedback. ChatGPT generated and revised the code, migration approach, tests, and documentation in response to that direction.

The project is not affiliated with, sponsored by, or endorsed by OpenAI, Brevo, or the original `sendEmail` project.
